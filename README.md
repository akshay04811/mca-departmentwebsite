# Department of Computer Applications (MCA) Website
### Mohandas College of Engineering & Technology (MCET)

A clean, responsive, beginner-friendly academic website designed exclusively with **semantic HTML5** and **CSS3**.

---

## 🏛️ Project Information

- **Institution**: Mohandas College of Engineering & Technology (MCET), Nedumangad, Thiruvananthapuram, Kerala
- **Department**: Department of Computer Applications (MCA)
- **Programme**: Master of Computer Applications (2-Year Full-Time PG Degree)
- **Technology Stack**: Pure **HTML5** & **CSS3** only (Zero JavaScript, no external libraries, no frameworks)
- **Execution**: Can be viewed directly by double-clicking `index.html` in any modern web browser (Google Chrome, Firefox, Safari, Edge) without requiring web servers, Node.js, or build steps.

## 🎨 Design System & Visual Palette

- **Institutional Primary (Navy Blue)**: `#123B68`
- **Accent Color (Crimson / Deep Red)**: `#A9002B`
- **Backgrounds**: `#FFFFFF` (White) and `#F6F7F9` (Subtle Light Gray)
- **Body Typography**: Clean cross-platform system font stack (`Segoe UI`, `Roboto`, `Helvetica Neue`, `Arial`, sans-serif)
- **Visual Features**: Red underline accents on section titles, subtle card hover elevations (`translateY(-5px)`), and a two-level college header.

---

## 📱 Responsive Design Breakpoints

The stylesheet employs clean, standard CSS3 media queries without any JavaScript:
- **Desktop (1200px+)**: Multi-column grids (3 to 4 columns for highlights, faculty, events, and gallery).
- **Tablet (max-width: 992px & 768px)**: Balanced 2-column grids; navigation links wrap gracefully across multiple lines without requiring a JavaScript hamburger toggle.
- **Mobile (max-width: 480px)**: Single column stacked layout, full-width touch-friendly buttons, and high text legibility.

---

## 🚀 How to Run the Website

1. Navigate to the `mca-department-website` directory on your computer.
2. Double-click **`index.html`** to open it in your default web browser (Chrome, Edge, Firefox, Safari).
3. All internal links (`about.html`, `hod.html`, `faculty.html`, `association.html`, `gallery.html`, `contact.html`) will navigate seamlessly offline.
